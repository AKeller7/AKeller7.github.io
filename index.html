Greenfield Salesforce Implementation

A documented approach by Ashley Keller, Salesforce Platform Architect

The Challenge

To replace a rigid, industry-specific legacy CRM that could not scale, was creating data silos, and relied on manual workarounds. The business needed a secure, reliable, and scalable platform to support its core operations and growth.

My Strategic Approach

Phase 1: Discovery & Strategy

  • Mapped all legacy objects, fields, and processes.
  • Partnered with department leaders to define "scalable" for their needs.
  • Planned migration to avoid replicating technical debt.

Phase 2: Core Architecture

  • Designed a scalable data model using Account Hierarchies for partners.
  • Implemented a modern, audit-ready Permission Set-Led Security Model following Principle of Least Privilege (PoLP).
  • Integrated Salesforce as the System of Record with Azure Data Lake.

Phase 3: Build & Automate

  • Built the core Lead-to-Cash process.
  • Automated the complex Client Account Closure workflow using Record-Triggered Flows with scheduled paths and external API integration.
  • Mentored a junior admin through an automation build.

Phase 4: Govern & Scale

  • Created comprehensive user training and documentation in Confluence.
  • Established a formal bi-weekly release process with sandbox promotion.
  • Defined ongoing governance standards for security and changes.

The Outcome

  • Successful Launch: Migrated all historical data (including critical partner payout data) without business disruption.
  • Eliminated Technical Debt: Replaced a failing system with a governed, scalable foundation.
  • Operational Efficiency: Automated key processes, saving one team ~75% manual effort.
  • Future-Proofed Growth: Established the architectural and governance standards necessary for scale.

This project embodies my approach: systems thinking, process orientation, and a focus on sustainable business outcomes.
